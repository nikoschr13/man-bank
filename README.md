# MAN Academy Daddy Bank — GitHub Pages package

Upload these four items to the root of the `nikoschr13/man-bank` repository:

- `index.html`
- `style.css`
- `script.js`
- the complete `assets` folder

In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose
`main` and `/ (root)`, then save. The address will be:

`https://nikoschr13.github.io/man-bank/`

GitHub Pages cannot execute Streamlit or Python. Files such as
`man_bank_girls_readonly.py`, `man_bank_marita_readonly.py`, and
`requirements.txt` belong on Streamlit Community Cloud instead. If a download
opens with GitHub navigation, buttons, or page styling around the code, it is a
saved GitHub webpage—not the raw source. Use the repository file’s **Raw**
button before saving it.
